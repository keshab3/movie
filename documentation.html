1. Introduction & Project Goal

This document explains the structure and features of MovieSync. MovieSync is a multi-page static website made with HTML and CSS. It works as a modern and responsive website for a movie theater.

The main goal of this project is to create a simple and user-friendly website where users can:

  • Find trending and upcoming movies.
  • See movie details like trailer, story, and cast.
  • Book tickets for different cinema halls (simulation).
  • Explore movie collections and know about the team.
  • View contact details and use the contact form.

4. Video Modal Feature

A key feature of the website is the in-page video player. Instead of redirecting users to YouTube, clicking on a movie card or trailer button opens a responsive popup (modal) that plays the video directly on the site.

  • How it works: We use Bootstrap's modal component. Each movie link has a special data-video-id attribute containing the YouTube video ID.
  • JavaScript Control: Our script.js file listens for the modal opening, grabs the video ID, and loads it into the iframe. When the modal closes, the script clears the iframe's source to stop the video.
<!-- Example of a movie card link that triggers the modal -->
<a href="#" data-bs-toggle="modal" data-bs-target="#videoModal" data-video-id="sjOTjbUo5OI">
    <div class="movie-card">...</div>
</a>

8. Detailed CSS Styling

7. Detailed CSS Styling

This section explains the main CSS features used to make the site responsive and clean.

Flexbox & Grid Layout

Flexbox and Grid are used to arrange items properly.

  • Flexbox (display: flex):
    • Where used: Navigation bar (.navbar ul) and book ticket section (.book-ticket).
    • Why used: Helps align items in one direction (row/column).
  • Grid Layout (display: grid):
    • Where used: Movies, collections, team section, and footer links.
    • Why used: Helps create responsive grid layouts.
/* Example: Responsive Grid for Movies */
.movies-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

Pseudo-elements (::before, ::after)

Pseudo-elements add design without adding extra HTML tags.

  • Where used: Hero overlay and heading left red line.
  • Why used: Keeps HTML clean and adds only decorative design.
/* Example: Gradient Overlay */
.movie-detail-banner::after {
  content: '';
  position: absolute;
  top: 0; left: 0; width: 100%; height: 100%;
  background: linear-gradient(to top, rgba(20, 20, 20, 1) 10%, ...);
}

Animations (@keyframes and animation)

Animations make the UI more attractive and interactive.

  • Where used: Pulsing border for team images (@keyframes pulse-border) and button hover effect (.btn:hover { transform: scale(1.05); }).
  • Why used: Adds smooth effects without using JavaScript.
/* Example: Pulsing Border Animation */
@keyframes pulse-border {
  from { border-color: #db0000; }
  to { border-color: #ffffff; }
}
.team-box img {
  animation-name: pulse-border;
  animation-duration: 2s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}

Media Queries (@media)

Media queries help the website work well on different screen sizes.

  • Where used: Mobile menu, font sizes, and grid stacking on small screens.
  • Why used: Makes the website responsive for mobile, tablet, and desktop.
/* Example: Responsive Font Size */
@media (max-width: 768px) {
  .hero-content h1 { font-size: 40px; }
  .navbar { display: none; } /* Hiding navbar on small screens */
}

10. Challenges & Solutions

9. Challenges & Solutions

During development, we faced some problems and solved them in a simple way.

Challenge: Maintaining Consistent Styling

Problem: CSS was first written inside each HTML page, which created repeated code.

Solution: We moved all CSS into one file: style.css. Now updates are easy and consistent.

Challenge: Consistent Team Section

Problem: The team layout looked different on the team page and contact page.

Solution: We used a common class and changed the layout to display: grid so both pages match.

Challenge: Responsive Iframes

Problem: YouTube and Google Map iframes were not responsive on mobile screens.

Solution: We wrapped iframes in a container and used CSS to keep a 16:9 ratio for better responsiveness.

Challenge: Keeping Users on the Website

Problem: Clicking a movie card redirected users to YouTube, which takes them away from our website and disrupts the user experience.

Solution: We implemented a Bootstrap modal with custom JavaScript. Now, videos play in a clean popup on the same page. This improves user retention and provides a more professional feel.

Challenge: Selecting Theme and Wireframe

Problem: At the beginning of the project, we were confused while selecting the website theme and wireframe. We discussed ideas like a mobile phone seller website, a travel website, a celebrity page, and a movie website.

Solution: After discussion, we selected the movie website theme and wireframe. This helped us plan the pages clearly and continue the project.
